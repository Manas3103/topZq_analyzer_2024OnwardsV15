# Production metadata examples

These seven JSON contracts contain SYNTHETIC illustrative identities and evidence;
they are not production records or accepted outputs. Some hashes/UUIDs were made
from local synthetic tests and do not identify a usable production package.
`campaign.json` is the preparation input. Use exact original inputs, approved
configs/profiles and a frozen source/payload identity for a real campaign.
Its no-clobber capability is intentionally false until independently tested.
`downstream_preferences.json` is documentation of decisions and pending grouping,
not input to the production processor or approval to run histograms.
See ../../campaign_production.md for contracts, limits and unresolved live gates.
